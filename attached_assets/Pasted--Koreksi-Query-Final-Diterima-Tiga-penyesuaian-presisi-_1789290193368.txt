Tiga penyesuaian presisi yang saya kunci:

## 1. Nama Tabel Drizzle
```
staffInvitationsTable  ✓  (bukan invitationsTable)
```

## 2. Normalisasi Email
Email sudah di-lowercase **saat invitation dibuat**, bukan saat matching. Query cukup pakai `inArray` langsung tanpa `LOWER(...)`.

## 3. Validasi Expiry + Pemilihan Terbaru
Query harus:
- Filter `status = 'PENDING'`
- Filter `expiresAt > now()` (undangan belum kedaluwarsa)
- `ORDER BY createdAt DESC` + `LIMIT 1` → ambil undangan terbaru jika ada multiple matches

## Query Aktual yang Benar

```typescript
const [invitation] = verifiedEmails.length
  ? await tx
      .select()
      .from(staffInvitationsTable)
      .where(
        and(
          inArray(staffInvitationsTable.email, verifiedEmails),
          eq(staffInvitationsTable.status, "PENDING"),
          sql`${staffInvitationsTable.expiresAt} > now()`,
        ),
      )
      .orderBy(desc(staffInvitationsTable.createdAt))
      .limit(1)
  : [];
```

| Aspek | Alasan |
