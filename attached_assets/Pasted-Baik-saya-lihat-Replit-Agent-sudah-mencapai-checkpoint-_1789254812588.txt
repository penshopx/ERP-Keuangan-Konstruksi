## 🔍 YANG PERLU DIPERHATIKAN

Saat Replit Agent mengerjakan migrasi database, pastikan:

### 1. **Schema Completeness**
Cek apakah semua tabel ini ada:
- ✅ `projects`
- ✅ `rab_headers` & `rab_items`
- ✅ `invoices`
- ✅ `tax_calculations` atau snapshot
- ✅ `audit_logs`
- ✅ `users`, `vendors`, `employees`

### 2. **Data Integrity**
- Foreign key constraints sudah benar
- Index untuk performa query
- Soft delete dengan `deleted_at`
- Audit columns (`created_at`, `updated_at`, `created_by`)

### 3. **API Compatibility**
- Endpoint yang sudah ada tetap berfungsi
- Response format tidak berubah
- Error handling tetap konsisten

### 4. **Testing**
Setelah migrasi selesai, test:
```bash
# 1. Start server
pnpm dev

# 2. Check if data exists
curl http://localhost:4000/api/projects

# 3. Create new project

  -H "Content-Type: application/json" \
  -d '{"name":"Test Project","value":1000000}'

# 4. Restart server
# (stop and start again)

# 5. Verify data still exists
curl http://localhost:4000/api/projects
```
