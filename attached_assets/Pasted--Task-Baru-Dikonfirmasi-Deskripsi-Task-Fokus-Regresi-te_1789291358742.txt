# ✅ Task Baru Dikonfirmasi

## Deskripsi Task

**Fokus:** Regresi test untuk atomicity pembuatan proyek.

**Masalah yang dicegah:**
```
Skenario gagal yang TIDAK boleh terjadi:
  ✅ INSERT projects → berhasil
  ❌ INSERT rab_headers (baseline) → gagal
  ❌ INSERT audit_log → tidak tercapai
  
  Hasil: proyek tersimpan TANPA baseline RAB dan audit → data setengah jadi
```

**Yang diharapkan:**
```
Skenario yang benar (atomic):
  ✅ INSERT projects
  ❌ INSERT rab_headers → gagal
  
  → ROLLBACK seluruh transaksi
  → projects TIDAK tersimpan
  → audit log mencatat kegagalan
  → Response: 500 dengan pesan yang jelas
```

## Tiga Operasi yang Harus Atomic

| # | Operasi | Tabel | Wajib? |
|---|---------|-------|--------|
| 1 | Insert proyek | `projects` | ✅ Ya |
| 2 | Insert baseline RAB | `rab_headers` + `rab_items` | ✅ Ya |
| 3 | Insert audit log | `audit_log` | ✅ Ya |
