## 🗄️ DATABASE SCHEMA (Prisma) - PRIORITAS

Buat schema.prisma dengan entitas inti berikut:

### Master Data
1. **Company** - Data perusahaan (NPWP, kualifikasi, jenis usaha: PELAKSANA/PERENCANA/PENGAWAS)
2. **User** - User dengan role (SUPER_ADMIN, DIRECTOR, PROJECT_MANAGER, SITE_MANAGER, FINANCE, TAX_STAFF, PROCUREMENT)
3. **Vendor** - Subkontraktor & supplier (dengan SBU, NPWP, kualifikasi UMKM/NON_UMKM)
4. **Employee** - Karyawan proyek
5. **ChartOfAccount** - COA 5 digit

### Project & Budget
6. **Project** - Master proyek (code, name, owner, contract_value, start_date, end_date, retention_percent, status)
7. **WBSNode** - Work Breakdown Structure (parent_id, code, name, level)
8. **RABHeader** - Header RAB (version, is_baseline, approved_at)
9. **RABItem** - Detail RAB (wbs_code, description, volume, unit, unit_price, total_price, category: MATERIAL/LABOR/EQUIPMENT/OVERHEAD)

### Procurement & Execution
10. **PurchaseRequest** - PR dari site
11. **PurchaseOrder** - PO ke vendor (linked to RABItem)
12. **GoodsReceipt** - Penerimaan barang di site
13. **SiteExpense** - Biaya langsung lapangan
14. **Subcontract** - Kontrak subkon
15. **SubcontrOpname** - Opname pekerjaan subkon
16. **SubcontrBackcharge** - Potongan subkon

### Billing & Finance
17. **Invoice** - Termin ke owner (dpp, ppn_amount, pph_final_amount, retention_amount, grand_total)
18. **Payment** - Pembayaran ke vendor/subkon
19. **RetentionLedger** - Pencatatan retensi
20. **AccountingEntry** - Jurnal akuntansi (double-entry)

### Tax
21. **FakturPajakOutput** - Faktur Pajak PPN
22. **BuktiPotongPPh42** - Bupot PPh Final konstruksi
23. **BuktiPotongPPh23** - Bupot PPh 23

### Audit
24. **AuditLog** - Audit trail (entity, action, user, old_value, new_value, timestamp)

**ATURAN DATABASE:**
- Semua tabel punya `created_at`, `updated_at`, `created_by`, `updated_by`
- Gunakan UUID untuk primary key
- Gunakan enum untuk status dan kategori
- Tambahkan index untuk kolom yang sering di-query
- Soft delete dengan `deleted_at`

## 🔐 AUTHENTICATION & AUTHORIZATION

- JWT-based auth (access token 15 menit, refresh token 7 hari)
- Password hashing dengan bcrypt (10 rounds)
- Middleware `requireAuth` untuk protected routes
- Middleware `requireRole(['FINANCE', 'DIRECTOR'])` untuk role-based access
- Refresh token rotation

## 📊 BUSINESS RULES (HARD-CODE)

1. **Budget Control**: PO + SiteExpense untuk satu WBS TIDAK BOLEH melebihi RAB Item total_price
2. **Immutable Ledger**: Invoice/Payment yang sudah POSTED tidak bisa diedit, hanya reversal
3. **Tax Calculation**: Otomatis saat create invoice/payment, tidak bisa di-override manual
4. **Retention**: Tidak bisa dicairkan sebelum `retention_release_date`
5. **Onerous Contract**: Jika estimated_cost > contract_value, wajib akui loss

## 🎯 ATURAN CODING

1. **TypeScript Strict**: Semua file harus `.ts` atau `.tsx`, no `any`
2. **Modular**: Satu folder = satu fitur, tidak boleh cross-import antar module kecuali via shared
3. **Validation**: Semua input divalidasi dengan Zod di layer controller
4. **Error Handling**: Gunakan custom error classes, response format konsisten:
   ```json
   {
     "success": true/false,
     "data": {...},
     "message": "...",
     "errors": [...]
   }
   ```
5. **Comments**: Jelaskan business logic kompleks dengan komentar
6. **Naming**: 
   - Files: kebab-case (`purchase-order.service.ts`)
   - Classes: PascalCase (`PurchaseOrderService`)
   - Functions: camelCase (`calculateTotal`)
   - DB tables: snake_case (`purchase_orders`)
7. **Environment**: Gunakan `.env` untuk semua konfigurasi, jangan hardcode
8. **Testing**: Minimal unit test untuk tax engine & business rules
