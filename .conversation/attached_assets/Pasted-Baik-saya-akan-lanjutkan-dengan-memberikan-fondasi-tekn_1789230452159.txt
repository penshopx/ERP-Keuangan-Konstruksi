## 1. Arsitektur Modul Aplikasi

Aplikasi ini sebaiknya dibagi menjadi **7 modul utama** yang saling terintegrasi:

| No | Modul | Fungsi Utama |
|----|-------|--------------|
| M1 | **Project Management** | Setup proyek, WBS, tim, site |
| M2 | **Estimasi & RAB** | BOQ, HSP, RAB, Kurva S rencana |
| M3 | **Procurement & Inventory** | PR, PO, DO, stok gudang proyek |
| M4 | **Execution & Cost Control** | Daily report, opname, progres fisik, HPP |
| M5 | **Billing & Receivable** | Termin, invoice, retensi, piutang |
| M6 | **Finance & AP** | Pembayaran vendor/subkon, kas kecil, bank |
| M7 | **Tax Engine & Compliance** | PPh 4(2), PPN, PPh 21/23, e-Faktur, SPT |

Di atas semua modul ini ada **Dashboard & Reporting Layer** yang menyajikan KPI proyek, cashflow forecast, dan laporan pajak.

## 2. Skema Database Inti (Core Schema)

Berikut adalah desain tabel-tabel kunci yang menjadi tulang punggung sistem. Saya menggunakan pendekatan **relasional (SQL)** karena transaksi keuangan membutuhkan integritas data yang ketat.

### 2.1. Master Data

```sql
-- Perusahaan / User
CREATE TABLE companies (
    id UUID PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    npwp VARCHAR(20) NOT NULL,
    qualification VARCHAR(20), -- 'UMKM', 'KECIL', 'MENENGAH', 'BESAR'
    business_type VARCHAR(30), -- 'PELAKSANA', 'PERENCANA', 'PENGAWAS'
    is_pkp BOOLEAN DEFAULT TRUE, -- Pengusaha Kena Pajak
    created_at TIMESTAMP DEFAULT NOW()
);

-- Master Proyek
CREATE TABLE projects (
    id UUID PRIMARY KEY,
    code VARCHAR(30) UNIQUE NOT NULL,
    name VARCHAR(255) NOT NULL,
    owner_id UUID REFERENCES companies(id), -- Pemilik proyek (client)
    contract_value DECIMAL(18,2) NOT NULL,
    start_date DATE,
    end_date DATE,
    retention_percent DECIMAL(5,2) DEFAULT 5.00,
    pph_final_rate DECIMAL(5,4), -- Diset otomatis dari tax engine
    status VARCHAR(20) DEFAULT 'PLANNING'
);
```

### 2.2. RAB & BOQ (Budgeting)

```sql
-- Header RAB
CREATE TABLE rab_headers (
    id UUID PRIMARY KEY,
    project_id UUID REFERENCES projects(id),
    revision INT DEFAULT 1,
    total_amount DECIMAL(18,2),
    approved_at TIMESTAMP,
    is_baseline BOOLEAN DEFAULT FALSE
);

-- Detail BOQ (Bill of Quantities)
CREATE TABLE rab_items (
    id UUID PRIMARY KEY,
    rab_header_id UUID REFERENCES rab_headers(id),
    wbs_code VARCHAR(30), -- Work Breakdown Structure
    description TEXT,
    volume DECIMAL(12,3),
    unit VARCHAR(20),
    unit_price DECIMAL(15,2),
    total_price DECIMAL(18,2),
    is_material BOOLEAN,
    is_labor BOOLEAN,
    is_equipment BOOLEAN
);
```

### 2.3. Transaksi Keuangan & Termin

```sql
-- Invoice / Termin (Billing)
CREATE TABLE invoices (

    invoice_no VARCHAR(50) UNIQUE,

CREATE TABLE payments (
    id UUID PRIMARY KEY,
    invoice_id UUID REFERENCES invoices(id),
    payment_date DATE,
    amount DECIMAL(18,2),
    payment_method VARCHAR(20), -- 'TRANSFER','CEK','GIRO'
    reference_no VARCHAR(50),
    created_by UUID
);
```

## 3. Tax Engine (Logika Perpajakan)

Ini adalah **jantung regulasi** aplikasi. Berikut pseudocode untuk menghitung pajak konstruksi sesuai regulasi Indonesia (PP 36/2023 dan perubahannya):

```javascript
class ConstructionTaxEngine {
    
    // Tarif PPh Final 4(2) berdasarkan jenis usaha & kualifikasi
    static PPH_FINAL_RATES = {
        PELAKSANA: {
            UMKM:    1.75,  // Qualifikasi Usaha Kecil
            NON_UMKM: 2.50  // Qualifikasi Menengah/Besar
        },
        PERENCANA: {
            UMKM:    3.50,
            NON_UMKM: 4.00
        },
        PENGAWAS: {
            UMKM:    3.50,
            NON_UMKM: 4.00
        }
    };
    
    // PPN konstruksi (sesuaikan regulasi terbaru)
    static PPN_RATE = 0.11;
    
    /**
     * Hitung pajak untuk satu invoice/termin
     */
    static calculateInvoiceTaxes(invoice, contractor, project) {
        const dpp = invoice.dpp; // Nilai pekerjaan sebelum pajak
        
        // 1. PPh Final 4(2) - dipotong oleh pemotong pajak
        const pphRate = this.getPphRate(contractor);
        const pphFinal = dpp * pphRate;
        
        // 2. PPN 11% - jika kontraktor PKP
        let ppn = 0;
        if (contractor.is_pkp) {
            ppn = dpp * this.PPN_RATE;
        }
        
        // 3. Retensi (biasanya 5% dari DPP)
        const retention = dpp * (project.retention_percent / 100);
        
        // 4. Grand Total yang dibayar ke kontraktor
        // = DPP + PPN - PPh Final - Retensi
        const grandTotal = dpp + ppn - pphFinal - retention;
        
        return {
            dpp: dpp,
            pph_final: pphFinal,
            pph_final_rate: pphRate,
            ppn: ppn,
            retention: retention,
            grand_total: grandTotal,
            net_receivable: grandTotal
        };
    }
    
    static getPphRate(contractor) {
        const type = contractor.business_type; // PELAKSANA/PERENCANA/PENGAWAS
        const qual = contractor.qualification; // UMKM/NON_UMKM
        return (this.PPH_FINAL_RATES[type][qual] / 100);
    }
    
    /**
     * Generate nomor faktur pajak (format e-Faktur)
     */
    static generateFakturNumber(company, sequence) {
        const kode = company.faktur_code || '010';
        const now = new Date();
        const mm = String(now.getMonth() + 1).padStart(2, '0');
        const yyyy = now.getFullYear();
        const seq = String(sequence).padStart(8, '0');
        return `${kode}.000-${mm}.${yyyy}.${seq}`;
    }
}
```

### Contoh Perhitungan Nyata

Sebuah termin pekerjaan dengan DPP = Rp 1.000.000.000, kontraktor pelaksana Non-UMKM, PKP:

| Komponen | Perhitungan | Nilai |
|----------|-------------|-------|
| DPP | - | Rp 1.000.000.000 |
| PPN 11% | 11% × DPP | Rp 110.000.000 |
| PPh Final 4(2) | 2.5% × DPP | (Rp 25.000.000) |
| Retensi 5% | 5% × DPP | (Rp 50.000.000) |
| **Net Diterima** | | **Rp 1.035.000.000** |

## 4. Alur Bisnis Kritis (Critical Path)

Berikut flow dari kontrak sampai pelaporan pajak:

```
[1] KONTRAK DITERIMA
    ↓
[2] INPUT RAB / BOQ → Jadi Baseline Anggaran
    ↓
[3] EKSEKUTI PEKERJAAN
    ├─→ PR → PO → DO Material
    ├─→ Daily Report (Upah, Alat)
    └─→ Opname Progres Fisik (%)
    ↓
[4] KLAIM TERMIN
    ├─→ Hitung nilai berdasarkan progres fisik
    ├─→ Tax Engine hitung: PPh 4(2) + PPN + Retensi
    └─→ Generate Invoice + Faktur Pajak
    ↓
[5] PEMOTONGAN PAJAK
    ├─→ Client memotong PPh Final (terbit Bupot)
    ├─→ PPN dipungut / self-collected
    └─→ Retensi ditahan sampai masa pemeliharaan
    ↓
[6] PELUNASAN & PELAPORAN
    ├─→ Rekonsiliasi piutang
    ├─→ Setor PPN ke kas negara (SSP)
    └─→ SPT Masa PPh Final & PPN
```

## 5. Rekomendasi Tech Stack

Untuk skala aplikasi ini (multi-tenant, real-time, mobile-friendly untuk site):

| Layer | Rekomendasi | Alasan |
|-------|-------------|--------|
| **Backend** | **Go (Gin/Echo)** atau **Node.js (NestJS)** | Performa tinggi untuk kalkulasi & transaksi |
| **Frontend Web** | **React + TypeScript + Ant Design** | Komponen tabel & form kompleks |
| **Mobile App** | **Flutter** | Untuk Site Manager di lapangan (offline-capable) |

| **Queue** | **RabbitMQ / BullMQ** | Generate laporan PDF, export Excel, e-Faktur |
