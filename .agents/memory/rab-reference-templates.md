---
name: RAB reference templates
description: Rules for using uploaded Indonesian RAB learning materials as reusable project templates.
---

Use the uploaded RAB documents to normalize WBS hierarchy, quantities, units, resource cost components, and calculation structure. Do not present prices from those documents as a current regional price database.

**Why:** The references span different years, project types, and educational examples. Their structures are useful, but their unit prices are not consistently dated or authoritative.

**How to apply:** Label template prices as references, require an explicit location/period adjustment factor, import into a new draft baseline version, and preserve all prior baselines unchanged.
